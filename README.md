# VK Groups → Telegram Bot

Бот на **aiogram+aiohttp** для автоматического переноса постов из VK-сообществ в Telegram-каналы, группы и чаты.

---

## Порядок установки

Создать `.env`

```env
BOT_TOKEN=...
VK_TOKEN=...
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Запустить:

```bash
python app/main.py
```

## Получение токенов


### Telegram Bot Token

1. Откройте `@BotFather` в Telegram.
2. Выполните команду `/newbot`.
3. Далее выберите своего бота и нажмите *API Token* :

### VK API Token

1. Перейдите по ссылке `https://dev.vk.com/ru`.
2. Во вкладке *"Приложение"* создайте приложение типа **"Мини-приложение"**.
3. Перейдите в *Настройки приложения* -> *Разработка* -> *Ключи доступа*
4. Вам необходимо получить *Сервисный ключ*

После получения токенов укажите их в конфигурации проекта.
